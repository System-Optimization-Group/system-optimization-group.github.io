**SCIP** (Solving Constraint Integer Programs) is currently one of the fastest non-commercial solvers for mixed integer programming (MIP) and mixed integer nonlinear programming (MINLP). It is also a versatile framework for constraint integer programming and branch-cut-and-price algorithms.

SCIP is developed as open source and distributed under the Apache 2.0 license as part of the [SCIP Optimization Suite](https://scipopt.org).
